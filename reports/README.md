# Reports Directory

This directory contains all logs, metrics, and audit trails generated by the pipeline.

## Files Generated

### discovery.csv
Lists all repositories discovered and fetched from GitHub.

**Columns:**
- `repo`: Repository name (owner/name)
- `commit_sha`: Git commit SHA at fetch time
- `size`: Repository size in KB
- `stars`: Number of GitHub stars
- `fetched_at`: Timestamp of fetch

### quarantine.csv
Records all files that failed license or security checks.

**Columns:**
- `repo`: Repository name
- `path`: File path within repository
- `reason`: Why the file was quarantined
- `checker`: Which checker flagged it (license/security)
- `evidence`: Supporting evidence (license name, security findings)
- `timestamp`: When the file was quarantined

### provenance.jsonl
Complete audit trail for every file processed (JSONL format - one JSON object per line).

**Fields:**
- `repo`: Repository name
- `path`: File path
- `sha`: Git SHA (if available)
- `hash`: Content hash (SHA-256)
- `status`: kept | dropped | quarantined
- `reason`: Explanation for the status
- `license`: Detected license
- `timestamp`: Processing time

**Example:**
```json
{"repo": "owner/repo", "path": "src/main.py", "hash": "abc123...", "status": "kept", "reason": "passed all checks", "license": "MIT", "timestamp": "2025-10-23T12:00:00Z"}
{"repo": "owner/repo", "path": "tests/test.py", "status": "dropped", "reason": "test file", "timestamp": "2025-10-23T12:00:01Z"}
```

## Usage

### Analyzing Quarantine Reasons

```bash
# Count quarantine reasons
cut -d',' -f3 reports/quarantine.csv | sort | uniq -c

# Find all GPL-licensed repos
grep "GPL" reports/quarantine.csv
```

### Reviewing Provenance

```bash
# Count kept vs dropped
grep '"status":"kept"' reports/provenance.jsonl | wc -l
grep '"status":"dropped"' reports/provenance.jsonl | wc -l

# Find all duplicates
grep '"reason":"duplicate"' reports/provenance.jsonl
```

### Viewing Metrics

```bash
# Pretty-print metrics
cat reports/metrics.json | jq .

# Get specific metric
cat reports/metrics.json | jq '.extraction.examples_extracted'
```

## Retention

These files serve as the official audit trail. Retain them for:
- Reproducibility verification
- Compliance audits
- Quality analysis
- Dataset provenance documentation

## Privacy

Do NOT commit these files if they contain:
- Repository paths with sensitive names
- Evidence fields with leaked secrets
- Any PII or confidential information

Add to `.gitignore`:
```
reports/*.csv
reports/*.jsonl
reports/metrics.json
```
